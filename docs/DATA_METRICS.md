# GEO 看板指标口径说明

本文档用“说人话”的方式解释看板上每个核心指标的含义、计算方式与数据来源，是看板数据可信度的依据。

## 一、数据从哪里来？

看板只有两种数据，不再有“模拟数据”：

| 来源 | 判定条件 | 看板表现 |
| --- | --- | --- |
| 真实采集 | 通过平台官方 API 或本地浏览器自动化，真实提问并记录 AI 回答（`CitationRecord.data_source` 为 `api` / `browser`） | 计入“真实采集”口径 |
| 预留演示 | 该平台暂时没有真实采集记录（或历史上只有旧模拟记录），导出时用提前准备好的种子数据补全 | 顶部横幅显示“其余为预留演示数据” |

> 注意：真实采集也可能出现“提到了 0 次”——这代表真实问到了回答，但品牌没有被提及，属于有效数据，不能和“没采到”混为一谈。

采集流程（GitHub Actions 每日运行）：

1. 优先调用各平台官方 API（需要配置 API Key）；
2. 本地环境 API 不可用时，用浏览器自动化真实提问；
3. CI 环境无法跑浏览器，真实采集失败的平台不造假，直接留空；
4. 导出阶段把留空的平台用“预留演示数据”补全，保证看板完整；
5. 接入真实 API 后，预留演示数据会自动被真实数据替换。

## 二、核心指标怎么算？

### 1. AI 被看见的程度（AI 可见性指数，0-100）

- 人话：综合判断“AI 回答里，我们品牌到底有多显眼、多正面”。
- 计算：所有平台 `visibility_score` 的平均值。
- 单平台可见性 = `引用率 × 0.4 + 情感正向度 × 0.3 + 推荐度 × 0.3`。
- 局限：权重是经验值，还没用业务转化率校准。

### 2. AI 提到品牌的比例（AI 引用率，%）

- 人话：我们拿一批和业务相关的提问去问 AI，回答里提到“嗖马/SomaAI”的占比。60% = 10 个问题里有 6 个回答提到了我们。
- 计算：`提到品牌的回答条数 ÷ 总提问条数 × 100`。
- 局限：提到不等于推荐，也不代表正面；要看推荐份额请结合“好感度”。

### 3. 大模型提到品牌次数（品牌提及频率）

- 人话：同一批提问里，所有 AI 回答中出现“嗖马/SomaAI”等品牌词的总次数。次数越多，品牌在 AI 回答里越常见。
- 计算：用正则 + 品牌别名（嗖马、SomaAI、soma agent 等）统计回答文本中的品牌词出现次数。
- 局限：口语化或英文变体可能漏匹配。

### 4. AI 对品牌的好感度（情感好感度，0-100）

- 人话：AI 提到我们时，语气是夸还是踩。
- 计算：每条回答先算情感分（-1 到 1），取平均后映射成 `(平均分 + 1) × 50`。
- 当前实现：规则关键词计数（推荐/优秀/高效 vs 不推荐/差/贵），可选更先进的模型。
- 局限：关键词法对反讽、隐式否定不敏感。

### 5. AI 推荐带来的访问量（AI 引荐流量）

- 人话：估算“被 AI 提及和推荐后，可能带来多少访问”。它是看趋势的相对指数，不是网站统计工具测出的真实流量。
- 计算：`提及次数 × max(1, 11 - 平均引用排名) × 15`。
- 局限：真实归因需要接入 UTM 参数 + 落地页问卷。

### 6. 官网被 AI 读懂的程度（结构化数据健康度）

- 人话：官网的 Schema 结构化数据、sitemap 等基础做得好不好；做得越好，AI 越容易正确引用官网信息。
- 计算：当日 `authority_score` 的平均值（信源权威信号比例）。

### 7. 提及位置（引用排名，1-10）

- 人话：品牌第一次出现在 AI 回答里的位置靠不靠前。1 = 最靠前。
- 计算：品牌首次出现位置占回答总长度的比例映射（前 5% → 1，每 10% 升一档）。
- 局限：启发式估算，不是平台官方排名。

## 三、KPI 环比

- 计算：近 7 天均值/总量 vs 前 7 天均值/总量，百分比变化。
- 需要至少 14 天历史，否则显示“暂无对比”。
- 双口径：`kpi_changes`（全部平台）、`kpi_changes_real`（仅真实采集平台）。

## 四、趋势数据

- 只基于真实采集平台构建，避免演示历史污染。
- 没有真实平台时返回空数组，前端显示“暂无真实趋势数据”。

## 五、更新频率与可追溯性

- GitHub Actions 每天 UTC 03:00 采集 → 导出 JSON → 提交；Render 自动部署。
- 原始 AI 回答保存在 `CitationRecord.raw_response`，可通过 API 追溯。
- 2026-08-29 起已停用“模拟数据”：不再生成编造的 AI 回答；真实数据不足时只用预留演示数据补齐看板。
