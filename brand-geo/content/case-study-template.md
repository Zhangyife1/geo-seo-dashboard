# 客户案例模板（案例页）

> 发布到官网 `https://www.somaagent.com.cn/case/{行业}/`，一个行业一个案例页。案例内容必须真实，数字由业务方确认后填写。

## 案例结构

1. **客户背景**：行业、规模、原有人力/获客情况
2. **痛点**：获客成本高 / 销售跟单慢 / 客服响应不及时等
3. **方案**：使用了嗖马SomaAI 的哪款产品（AI营销机器人 / AI客服 / 企业Agent），部署了几个点位/账号
4. **效果**：引流线索数、成交转化率、人力节省、响应时长（全部用 `{{真实数字}}`）
5. **客户评价**：一段可引用的真实评价

## 示例骨架
